📖 Sobre o Projeto

Conheça mais sobre este projeto educacional

Este portal de jogos foi desenvolvido como parte do Curso Técnico em Desenvolvimento de Sistemas do SENAC-DF, sob orientação do Prof. Pedro Renato.

Todos os jogos foram construídos utilizando HTML5, CSS3 e JavaScript puro, sem dependências externas, demonstrando habilidades em desenvolvimento web, lógica de programação e design responsivo. Os jogos são categorizados por nível de dificuldade para auxiliar no aprendizado progressivo.
